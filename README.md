# 隐秘浏览助手 (Stealth Browsing Assistant)

**Chrome网上应用商店：** [https://chromewebstore.google.com/detail/隐秘浏览助手/eholnkicainpbpdemghpkmjjgidjmpfb](https://chromewebstore.google.com/detail/%E9%9A%90%E7%A7%98%E6%B5%8F%E8%A7%88%E5%8A%A9%E6%89%8B/eholnkicainpbpdemghpkmjjgidjmpfb?authuser=2&hl=zh-CN)

隐秘浏览助手是一款专为增强浏览隐私设计的Chrome扩展程序。它允许您访问特定网站而不在Chrome的标准历史记录中留下痕迹，同时将这些访问记录保存在扩展内部的私密日志中，只有您能查看。

## 📥 安装方式

### Chrome网上应用商店
直接从Chrome Web Store安装：
[Chrome Web Store - 隐秘浏览助手](https://chromewebstore.google.com/detail/%E9%9A%90%E7%A7%98%E6%B5%8F%E8%A7%88%E5%8A%A9%E6%89%8B/eholnkicainpbpdemghpkmjjgidjmpfb?authuser=2&hl=zh-CN)

### 手动安装（开发版）
1. 下载或克隆本项目到本地
2. 打开Chrome浏览器，访问 `chrome://extensions/`
3. 启用"开发者模式"（右上角开关）
4. 点击"加载已解压的扩展程序"
5. 选择本项目的文件夹

## ✨ 核心功能

- **忽略名单管理**：通过设置页面轻松将网站添加到您的"忽略名单"中或从中移除
- **自动历史记录过滤**：对忽略名单中的网站的访问不会出现在Chrome的标准历史记录中
- **减少地址栏联想建议**：扩展程序尽量减少忽略网站在地址栏中的联想建议（受Chrome内部机制限制，可能无法完全消除）
- **隐私浏览日志**：在扩展程序内查看您访问忽略网站的记录，包括URL、标题和时间戳
- **快速切换功能**：通过弹出窗口一键将当前网站添加到忽略名单或从中移除
- **多语言支持**：界面同时支持英文和简体中文

## 💻 使用方法

### 添加网站到忽略名单
1. 在要忽略的网站上点击扩展图标
2. 点击"添加到忽略名单"按钮
3. 该网站及其子域名将被添加到忽略名单中

### 从忽略名单中移除网站
1. 在已忽略的网站上点击扩展图标
2. 点击"从忽略名单中移除"按钮

### 查看隐私浏览日志
1. 点击扩展图标
2. 点击"打开设置"
3. 在设置页面中，您可以查看、管理您的隐私浏览日志

### 管理忽略名单
1. 点击扩展图标
2. 点击"打开设置"
3. 在设置页面中，您可以查看和编辑您的忽略名单

## ⚠️ 重要说明

### 关于地址栏联想建议
由于Chrome的内部机制，被忽略网站的地址栏联想建议仍可能偶尔出现，尤其是在频繁访问后。扩展程序采用多种策略来最小化这种情况，包括：
- 实时删除匹配的历史记录
- 积极搜索并清理相关历史条目
- 定期清理与忽略域名相关的所有历史记录

### 隐私保护
- 所有数据（忽略名单和私密浏览日志）仅存储在本地设备上
- 扩展不会收集、存储或传输任何个人数据到外部服务器
- 您可以随时从设置页面删除单条记录或清空整个私密浏览日志

## 🛠️ 技术细节

- 使用Chrome扩展API `chrome.history.deleteUrl` 来移除历史记录
- 使用 `chrome.storage.local` 在本地存储忽略名单和私密浏览日志
- 利用 `chrome.webNavigation` 实时监控网页访问活动
- 通过 `i18n` API提供多语言支持

**为什么使用隐秘浏览助手？**

无论您是研究敏感话题、在共享设备上管理账户，还是仅仅希望保持某些浏览活动的私密性，隐秘浏览助手都提供了一个简单的解决方案，使您可以维护隐私而不必为特定网站频繁切换到无痕模式。
